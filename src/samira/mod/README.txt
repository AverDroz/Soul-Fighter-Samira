在以撒里玩暗裔Samira！
是的，你现在可以在《以撒的结合》里玩暗裔Samira了！

游玩前务必阅读：首次安装需要额外一步
仅订阅创意工坊还不够，请按以下步骤安装一次配套程序。

1. 订阅本 Mod，等待 Steam 下载完成，并在游戏 Mods 菜单中启用。
2. 在 Steam 库中右键《以撒的结合》，选择“管理 → 浏览本地文件”。
3. 进入 mods 文件夹，找到Samira Mod 目录。
4. 找到 Samira-Companion.zip，将它完整解压到一个固定目录，不要直接在压缩软件中运行。
5. 关闭游戏，运行解压后的 SamiraSetup.exe，确认以撒游戏目录（其中应有 Repentogon 文件夹），点击“安装”。
6. 以后正常通过忏悔龙启动器启动游戏，在角色选择界面选择 Samira 即可，不必每次运行安装器。

无需安装 Python、Codex 或英雄联盟客户端，也不需要输入控制台启动命令。

Samira拥有独立的生命值、经验等级和技能加点系统。通过战斗升级，在商店购买装备，并合成更强大的装备。
以撒原有道具依然会影响Samira，部分道具还有针对技能的特殊联动！此外，还接入了英雄联盟中的跳舞、嘲讽等特殊动作、技能特效和中英语音，界面与语音跟随游戏语言切换。

这是怎么实现的？
以撒本来是一款 2D 游戏，而这里的Samira使用实时 3D 模型、动作和技能特效。
本 Mod 采用“游戏内 Mod + 独立 Companion 配套程序”：游戏内 Mod 负责战斗、技能、道具交互和游戏数据；配套程序负责实时绘制模型、动画、特效和专属界面。这也是首次游玩需要安装配套程序的原因。

Play Samira in The Binding of Isaac!
Yes—you can now play the Samira Blade in The Binding of Isaac!

Read before playing: one-time companion installation required
Subscribing alone is not enough. Please complete these steps:

1. Subscribe, wait for Steam to finish downloading, and enable the mod in Isaac’s Mods menu.
2. In your Steam Library, right-click Isaac → Manage → Browse local files.
3. Open mods and find the Samira mod folder.
4. Fully extract Samira-Companion.zip to a stable folder. Do not run Setup inside an archive viewer.
5. Close Isaac. Run SamiraSetup.exe, select your Isaac game folder (containing Repentogon), and click Install.
6. Use your usual REPENTOGON launcher and select Samira. You do not need to run Setup every session.

No separate Python, Codex, League client or startup console commands required.

Meet the Samira Blade
Q — The Samira Blade: three heavy sword strikes with increasing damage.
W — Infernal Chains: slows the target and pulls it back if it fails to escape the marked area.
E — Umbral Dash: dash and reset your basic attack.
R — World Ender: spread your wings and gain attack damage, movement speed and increased healing!
Passive — Deathbringer Stance: an empowered basic attack that deals bonus damage and restores health.

Samira has numeric health, experience, levels and skill points. Level up through combat, buy items and combine them into stronger equipment. Isaac items still affect Samira, with dedicated ability synergies for some items. League animations such as dancing and taunting, ability effects, and English/Chinese voices are included.

How does it work?
Isaac is a 2D game; this mod adds a real-time 3D champion through an in-game mod and a separate Companion. Isaac handles combat, abilities, item interactions and game data. The companion draws the model, animations, effects and custom interface. That is why the one-time companion install is necessary.

Default: mouse mode.

P: shop; trade in cleared rooms.
S: stop movement/attacks.
F10: configuration.

Tap/release Ctrl to swap items; hold to drop.
Ctrl + 1–4: joke, taunt, dance, laugh; Ctrl + 5: toggle back banners.
WASD mode and controller input are supported. Check F10 for bindings.

Updates and troubleshooting
UI and voices follow the game language. When release notes require a Companion update, close Isaac and use Update in SamiraSetup.exe from the new ZIP.
Missing model or HUD? Check that you launched through REPENTOGON and installed the companion. Close Isaac and try Repair in Setup.
Use windowed or borderless fullscreen, not forced exclusive fullscreen. Setup also provides Uninstall; unsubscribing from the Workshop does not uninstall the companion.
