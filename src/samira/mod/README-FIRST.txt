Samira Samira｜开玩前看这里

需要：Windows 64 位，忏悔+，已安装的 REPENTOGON（忏悔龙），显卡支持 OpenGL 3.3。使用窗口或无边框全屏。

首次安装（只做一次）
1. 在游戏 Mods 菜单启用Samira。
2. 将本文件夹的 Samira-Companion.zip 完整解压，退出游戏，运行其中的 SamiraSetup.exe。
3. 选择以撒游戏目录（里面有 Repentogon 文件夹），点击“安装”。
4. 用你原来的忏悔龙启动器打开游戏，选择 Samira 就能玩！以后不用再开安装器。
无需安装 Python，Codex 或英雄联盟，也不用输入控制台命令。

怎么玩
右键：移动/攻击；A：朝鼠标自由攻击；QWER：技能；S：停止。
空格：主动物品；4：卡牌/胶囊；G：炸弹；P：商店（清房后交易）。
点击技能上方“+”或按 Ctrl+技能键加点。
Ctrl 短按：切换物品，长按：丢弃；Ctrl+1～5：切换翅膀显示。
F10：设置，改键，WASD 模式；支持手柄。界面和语音跟随游戏语言。

模型没出现？先确认是否用了忏悔龙启动器，然后退出游戏，用安装器点“修复”。提示拒绝访问时，请以管理员身份运行安装器。
需要更新配套时，解压新 ZIP，退出游戏，用新安装器点“更新”。卸载也在安装器里。只取消订阅不会完整的卸载。
普通 Mod 更新不用重装配套，除非更新公告要求。

语音位置（相对于本 Mod 文件夹）
英文：resources/sfx/samira/en/；中文：resources/sfx/samira/ 下的 vo_*.wav。
当前版本请勿直接删除：content/sounds.xml 仍引用这些文件，尚未验证缺文件时能安全加载。不要删除整个 samira 音效目录，其中还有技能音效与大招音乐。

English — Quick start

Requires Windows x64, Repentance+, REPENTOGON and OpenGL 3.3. Use windowed/borderless mode.

Install once:
1. Enable Samira in Isaac's Mods menu.
2. Fully extract this folder's Samira-Companion.zip. Close Isaac and run SamiraSetup.exe.
3. Select your Isaac game folder (containing Repentogon) and click Install.
4. Use your usual REPENTOGON launcher and select Samira. No need to run Setup again each session.
No Python, Codex, League client or console commands required.

Start at level 3: click + above abilities or press Ctrl+ability to spend points.
RMB move/attack; A free attack toward cursor; QWER abilities; S stop.
Space active item; 4 card/pill; G bomb; P shop (trade in cleared rooms).
Tap Ctrl to swap, hold to drop; Ctrl+1–5 emotes/banners.
F10 settings, rebinding and WASD mode. Controller supported. UI/voice follow game language.

Missing model? Check your REPENTOGON launcher, close Isaac and use Repair in Setup. For access denied, run Setup as administrator.
When a companion update is required, extract the new ZIP, close Isaac and use Update. Setup also provides Uninstall; unsubscribing does not uninstall the companion.
Mod 0.7.71 / Companion 0.7.71. Only update the companion when release notes request it.

Voice files (relative to this mod folder):
English: resources/sfx/samira/en/; Chinese: vo_*.wav in resources/sfx/samira/.
Do not directly delete them in this version: content/sounds.xml still references them, and loading with missing audio has not been verified. Do not delete the whole samira audio folder; it also contains skill sounds and ultimate music.
