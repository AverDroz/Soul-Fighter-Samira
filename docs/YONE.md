# Ёнэ в Isaac

Включи **Soul Fighter Samira** в Repentance+ с REPENTOGON, затем выбери **Yone** в новом одиночном забеге. Ёнэ начинает с трёх красных сердец. В личной Windows-сборке с моделью перед запуском игры открой `launch.cmd`, чтобы запустить Companion.

Для автоматической установки и запуска на Windows скачай готовый `Install-Yone.cmd` из выпуска. Установщик обновит `samira_testroom` в каталоге модов, который использует REPENTOGON, и проверит обе анимации выбора. Для загрузки нового меню полностью перезапусти Isaac. [Установщик Ёнэ](https://github.com/N1kromant/Soul-Fighter-Samira/releases/download/yone-immersion-v6/Install-Yone.cmd)

Полноэкранный режим у Ёнэ работает через окно без рамки. После смены режима или размера окна Companion проверяет новую область отрисовки, а штатный спрайт остаётся видимым до подтверждения свежего кадра. Q/W/E/R занимают фиксированные слоты и учитывают положение рюкзака.

| Клавиша | Действие |
| --- | --- |
| ПКМ по земле или открытой двери | Идти к точке или в соседнюю комнату |
| ПКМ по врагу | Подойти и атаковать, попеременно двумя клинками |
| Стрелки / S | Двигаться / отменить приказ |
| A | Ударить в направлении курсора |
| Q | Стальной выпад по врагам, кучам и ломаемым объектам. После двух попаданий Q3 выпускает вихрь и переносит Ёнэ вперёд до первой преграды |
| W | Взмах широким сектором. При попадании щит поглощает одну атаку врага |
| E | Оставить тело и выйти в форме духа. Удары помечают врагов. Повторная E или истечение таймера возвращает к телу и наносит 30% подтверждённого урона по меткам |
| R | Подготовить удар по широкой линии и переместиться за последнюю задетую цель. Удар и притяжение обычных врагов проходят через внутренние преграды. Если таймер E истечёт во время R, возврат дождётся конца ульты |
| G / 4 / Пробел | Бомба / карта или пилюля / активный предмет |
| Ctrl+1 / Ctrl+2 | Шутка / насмешка |
| Ctrl+3 / Ctrl+4 | Танец / смех |
| Ctrl+6 | Значок мастерства на четыре секунды. Повтор доступен через шесть секунд |

Удерживай Q, W, E или R, чтобы увидеть форму и дальность способности, затем отпусти клавишу для применения по курсору. Q/W/E/R восстанавливаются перед первым боем в каждой комнате. При смене комнаты незавершённый удар, значок и метки E сбрасываются. Способности, движение и полученный урон прерывают эмоцию. Ctrl+4 сохраняет карту или пилюлю, даже если отпустить Ctrl прежде цифры 4.

На отпускании клавиши зона Q, Q3, W или R фиксируется до конца замаха. Попадание и эффект рассчитываются в момент удара по этой зоне. В HUD у каждой способности есть значок, а слот E показывает, сколько осталось до возврата, и `HOLD`, если возврат ждёт завершения R. Отмеченные противники видны по ромбу над ними.

Companion проигрывает боевые клипы классической модели из локального клиента LoL. Обычный Q использует обе части исходной последовательности, Q3 — замах, рывок и приземление. Фазы сохраняют одну точку привязки на полу Isaac. Наклон камеры для модели Ёнэ составляет 50°, а её поворот вычисляется из экранного направления удара. Вспышки при попадании Q3, R и при срабатывании меток E привязаны к поражённым целям. [Умения Ёнэ у Riot](https://www.leagueoflegends.com/en-us/champions/yone/)

## Предметы и баланс

Ёнэ получает четыре бонусных предложения из пула 23 подходящих LoL-предметов и общий рюкзак на шесть слотов. Обычный ассортимент Isaac сохраняется. Перезарядки реагируют на ускорение умений. Крит LoL относится к автоатаке или Q и применяется к первой задетой цели. Возврат E, яд и горение не запускают проки заново.

Дальность слёз частично переносится на клинки. Mom’s Knife даёт ещё немного дальности, в сумме максимум +35%. 20/20, Inner Eye и Mutant Spider добавляют первой цели AA/Q/Q3 соответственно +40%, +57,5% и +75% урона с общим пределом +75%. Изменения базового урона и темпа от этих артефактов сохраняются. Common Cold, Fire Mind, Spider Bite и Mom’s Contacts могут дать статус первой задетой цели. Шанс 10–15% проверяется один раз на удар. Заморозка исключает боссов.

Trinity Force исключён из бонусной витрины Ёнэ. На тестовом старте с 3,5 урона и MaxFireDelay 9 он давал бы примерно ×2,44 ожидаемого урона автоатак в секунду ещё до Spellblade. В том же расчёте Infinity Edge даёт ×2,23, Yun Tal ×2,14 до настаканного крита, Kraken Slayer ×2,06 до третьего удара. Их стоит проверять первыми на раннем этаже и в полном забеге. Для Ёнэ спасательные эффекты Lifeline делят одно срабатывание на этаж и лечат 1½ красного сердца. Бонус Bastionbreaker при получении вне витрины ограничен меньшим из 15% здоровья босса и двух базовых ударов. Это стартовая настройка под ближний бой. Реальный темп забегов и экономика требуют игрового теста.

## Модель для сборки из исходников

Из репозитория можно запустить боевые механики и значок мастерства. Для модели и оригинальных анимаций установи зависимости и импортируй классические материалы из своего клиента League of Legends. Архив Hero Studio бери из закреплённого источника. Скрипт проверяет контрольную сумму архива. [Hero Studio v1.0.0](https://github.com/TFOS4/Isaac-LoL-HeroStudio/releases/tag/v1.0.0)

```powershell
python -m pip install 'cdtb==1.3.0' numpy
python tools/import_yone_assets.py --wad '<League of Legends>/Game/DATA/FINAL/Champions/Yone.wad.client' --herostudio-archive '<путь к архиву Hero Studio>'
```

Импорт пишет в `assets/yone-local/`. Эта папка предназначена для локальной сборки и игнорируется Git. Чтобы пользоваться Companion из исходников, запусти [внешний рендер](../src/samira-testroom/README.md#запуск). У Windows-экспорта есть отдельный флаг `--include-local-yone` для личного архива с импортированными материалами. Без модели Companion остаются стандартное игровое тело, текст эмоции и встроенный значок мастерства.

Оригинальные звуки эмоций, английские реплики и девять боевых звуков импортируются отдельно. Для этого нужны Python с CDTB, FFmpeg в `PATH` и закреплённые выпуски инструментов ниже. [wwiser v20260808](https://github.com/bnnm/wwiser/releases/tag/v20260808) · [vgmstream r2168](https://github.com/vgmstream/vgmstream/releases/tag/r2168)

```powershell
python tools/import_yone_emote_audio.py --wad '<Yone.wad.client>' --voice-wad '<Yone.en_US.wad.client>' --wwiser '<wwiser.pyz>' --vgmstream-archive '<vgmstream-win64.zip>'
```

Модель, анимации, звуки, портрет и значок мастерства принадлежат Riot Games. Для значка используются материалы мастерства из существующего проекта.
