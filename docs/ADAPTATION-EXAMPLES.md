# Примеры для обсуждения

Предложения, не утверждённый баланс. Числа ниже пробные; в игровой код они не внесены.

## Аугментации

| Аугментация | Идея оригинала | Предложение для Isaac |
|---|---|---|
| Firebrand | Автоатаки накладывают накапливающееся горение | Штатное горение, знакомое по Fire Mind, без случайных взрывов. Пули поджигают, повторные попадания обновляют эффект. Процент от HP и бесконечные стаки заменяем обычным уроном горения; Q может наследовать эффект как усиленный выстрел. |
| Deft | Существенная прибавка скорости атаки | +40% частоты автоатак через стат скорострельности, по принципу Wire Coat Hanger. Не ускоряет автоматически десять волн R и не уменьшает откаты W/E. |

Firebrand описан в https://wiki.leagueoflegends.com/en-us/Arena/Augments (вторичный источник). Deft есть в патчноуте Riot https://www.leagueoflegends.com/en-au/news/game-updates/league-of-legends-patch-26-11-notes/ . Аналоги Isaac: https://bindingofisaacrebirth.wiki.gg/wiki/Item_id .

## Предметы

| Предмет | Идея оригинала | Предложение |
|---|---|---|
| Infinity Edge | AD, шанс и сила крита | +1 Damage, +20 процентных пунктов шанса крита, +0.25 к его множителю. Использовать общий расчёт крита из основы; крит не является обычным Isaac Luck. |
| Berserker's Greaves | Скорость атаки и движения | +20% частоты автоатак, +0.15 MoveSpeed; статовые эффекты по принципу Wire Coat Hanger + Wooden Spoon. |
| Giant's Belt | Дополнительное здоровье | Один заполненный контейнер красного сердца, по принципу Lunch. Для этого принимаем нативную систему сердец; она пока предложение, исходный шаблон использует числовое HP. |
| Ionian Boots of Lucidity | Скорость и ускорение навыков | +0.15 MoveSpeed, множитель времени отката Q/W/E 0.85. Ульта остаётся привязана к S. |

Источники предметов: Riot Data Dragon, https://ddragon.leagueoflegends.com/cdn/16.22.1/data/en_US/item.json ; для Greaves/Belt также изучен комплектный equipment-data.json версии 16.21.1.

## Предлагаемые общие правила

- Нативные сердца вместо отдельного числового HP упростят взаимосвязь с Isaac; пользователь ещё не подтвердил.
- Дальние автоатаки используют игровые снаряды с видом пуль и нужными флагами. Это позволяет переиспользовать многие эффекты Isaac, но не гарантирует автоматическую поддержку всех предметов и схем стрельбы.
- Q/W/E/R получают эффекты по явной общей политике: что применяется к пуле, к удару клинком и к каждой волне R. Не переносить все проки на каждую волну без проверки.
- Не выдавать целый ванильный предмет вслепую, если у него есть ненужные эффекты/костюмы. Где возможно — только нужный стат или флаг.
- Магазин на 12 позиций для первого примера: 3 легендарных, 5 недорогих предметов, 4 расходника. Это проектный вариант для оценки, не согласованная квота.
- Предметы заполняются данными, аугментации собираются из общих эффектов; индивидуальный код только для действительно уникальных механик.
